## Tez boshlash

Toʻrtta tekshiruv kodni odam review qilishidan oldin muammolarning koʻpini ushlaydi: **type checker**, ehtimoliy bug'lar uchun **linter**, uslub hech qachon muhokama qilinmasligi uchun **formatter** va **ishlatilmagan kodni aniqlash**. Ularni saqlashda, pre-commit hook'da va — eng muhimi — CI'da ishga tushiring.

Qat'iy TypeScript'dan boshlang:

```json
// tsconfig.json (parcha)
{
  "compilerOptions": {
    "strict": true,
    "noUncheckedIndexedAccess": true,       // arr[i] — T | undefined
    "exactOptionalPropertyTypes": true,
    "noImplicitOverride": true,
    "verbatimModuleSyntax": true
  }
}
```

ESLint flat config faylidan foydalanadi:

```js
// eslint.config.js
import js from "@eslint/js";
import tseslint from "typescript-eslint";
import reactHooks from "eslint-plugin-react-hooks";

export default [
  js.configs.recommended,
  ...tseslint.configs.recommended,
  reactHooks.configs.flat.recommended,
  { ignores: ["dist/**", ".next/**"] },
];
```

Yoki formatlash va lint uchun bitta tool:

```bash
npx @biomejs/biome init           # biome.json yaratadi
npx @biomejs/biome check --write  # format + lint + import'larni tartiblash, tuzata olganini tuzatadi
```

## Qanday tanlash

| Vaziyat | Tanlov |
| --- | --- |
| Har doim | `strict`'li TypeScript |
| Framework qoidalari (Next.js, React hooks), type'ni biladigan qoidalar | ESLint |
| Eng keng editor qoʻllovli formatlash | Prettier |
| Format + lint uchun bitta tez tool va bitta config | Biome |
| Lint vaqti ogʻriq beradigan ulkan repo | Avval Oxlint, qolgan qoidalar uchun ESLint |
| Ishlatilmagan fayl, export va dependency'lar | Knip |

## Tuzoqlar

- Linter va formatter'ni urishtirmang: Prettier'ni ESLint bilan ishlatsangiz, ESLint'ning formatlash qoidalarini oʻchiring (`eslint-config-prettier`).
- Hamma izoh bilan oʻchiradigan qoida — shovqin; uni olib tashlang. Haqiqiy hodisani ushlay oladigan qoida — oltin; uni error'ga aylantiring.
- `any` tarqaladi. Chegaralarda `unknown`'ni afzal koʻring va tekshiring (validatsiya kategoriyasiga qarang).
